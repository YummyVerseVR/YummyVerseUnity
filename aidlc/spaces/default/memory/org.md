# Org-Level Rules

## Mandated

- 人間が読む成果物と承認依頼は、日本語で記述する。
- 事実、推論、仮定、未解決事項を区別し、根拠となるファイルまたは決定を示す。
- phase と stage の完了には、成果物のレビュー可能性と上流 ID へのトレーサビリティを要求する。
- アプリケーションコードは `aidlc/` の外に置き、AI-DLC 配下には状態、監査、設計、検証成果物だけを置く。
- 秘密情報、個人情報、認証情報を成果物へ記録しない。

## Forbidden

- 明示的な承認なしに approval gate を通過したものとして扱わない。
- 根拠のない完了、テスト成功、互換性、性能を主張しない。
- 安定 ID を再採番しない。
